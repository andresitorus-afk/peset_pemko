# Live Chat Real-time + Auto-Chatbot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah chat real-time visitor↔petugas via Laravel Reverb + auto-chatbot template FAQ 24 jam di website PESET.

**Architecture:** Backend Laravel (Reverb WebSocket terpisah, event broadcast ke channel privat), service `ChatbotService` pencocok FAQ template, REST API publik+staff; frontend Nuxt 3 dengan widget melayang publik + halaman admin live-chat + notifikasi real-time.

**Tech Stack:** Laravel 13, `laravel/reverb`, PostgreSQL 15, Nuxt 3, `laravel-echo` + `pusher-js`, Tailwind.

## Global Constraints

- UUID: `$table->uuid('id')->primary()->default(DB::raw('gen_random_uuid()'))` di semua tabel domain baru.
- Verifikasi backend dari **host**: `$env:DB_HOST='127.0.0.1'; $env:DB_PORT='5433'` di folder `backend`. JANGAN `migrate:fresh` (destruktif). `db:seed --class=X` sekali saja.
- Jangan mount source backend (image bake). Perubahan backend butuh `docker compose build backend`.
- Model model/table baru: `ChatSession`→`chat_sessions`, `ChatMessage`→`chat_messages`, `ChatbotFaq`→`chatbot_faqs`.
- Frontend: inline SVG icons (tanpa lib icon), Tailwind, pola modal/button existing.
- `php artisan test` dari host dengan env DB di atas.

### Task 3: ChatbotService + config fallback

**Files:**
- Create: `backend/app/Services/ChatbotService.php`
- Modify: `backend/config/services.php` (blok `chatbot`)
- Create: `backend/tests/Unit/ChatbotServiceTest.php`

- [ ] **Step 1: Tulis test DB-free** (`tests/Unit/ChatbotServiceTest.php`) — match keyword tunggal, skor tertinggi, tanpa cocok → null, normalisasi huruf besar/tanda baca.

- [ ] **Step 2: Implementasi**

```php
class ChatbotService {
    public static function normalize(string $s): string { return mb_strtolower(preg_replace('/[^\p{L}\p{N}\s]/u', ' ', $s)); }
    public static function match(string $message, array $faqs): ?array {
        $msg = self::normalize($message);
        $best = null; $bestScore = 0;
        foreach ($faqs as $f) {
            if (!$f['aktif']) continue;
            $score = 0;
            foreach ($f['keywords'] as $k) if (str_contains($msg, self::normalize($k))) $score++;
            if ($score > $bestScore) { $bestScore = $score; $best = $f; }
        }
        return $bestScore > 0 ? $best : null;
    }
}
```
